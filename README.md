# Data Science Project

This project demonstrates a full data science workflow, including data analysis, statistics, and modeling using Python. The main steps are:

1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory data analysis (EDA)
4. Statistical analysis
5. Modeling (machine learning)
6. Evaluation and conclusions

## Structure
- `data/` — Contains datasets
- `notebooks/` — Jupyter notebooks for analysis
- `scripts/` — Python scripts for modular code
